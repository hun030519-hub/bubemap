# bubemap
부산 지역 공공시설 및 강좌 통합 지도 웹 앱 (부비맵)
Vercel + Supabase 조합으로 운영할 수 있는 실시간 위치 기반 웹 앱입니다. 사용자는 별도의 로그인 없이 현재 위치를 기반으로 부산 지역 내 무료 공공시설과 실시간 신청 가능한 강좌 현황을 지도에서 확인하고 필터링할 수 있습니다.

기술 구성
Frontend: HTML / CSS / JavaScript (바닐라 JS 및 Kakao Map API 활용)

Backend/Database: Supabase (PostgreSQL 기반 데이터베이스 및 REST API)

Hosting: Vercel

Config: Vercel 환경변수 또는 로컬 config.js

Supabase 설정
Supabase에서 새 프로젝트를 생성합니다.

SQL Editor에서 아래 쿼리를 실행하여 공공시설 및 강좌 데이터를 적재할 테이블을 생성합니다.

SQL
create table public.busan_courses (
  id bigint generated by default as identity primary key,
  title text not null,          -- 강좌명
  facility_name text,          -- 시설명
  latitude double precision,   -- 위도
  longitude double precision,  -- 경도
  fee text,                    -- 수강료 (무료 여부 확인용)
  status text,                 -- 접수 상태 (접수중/마감)
  url text,                    -- 상세 페이지 링크
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
Database 메뉴에서 Python 스크립트나 API 크롤러를 통해 부산 공공데이터포털(data.busan.go.kr)의 데이터를 이 테이블에 주기적으로 동기화(Upsert)하도록 세팅합니다.

Project Settings > API에서 URL과 anon public API key를 확인합니다.

로컬 실행
config.example.js를 복사해 config.local.js를 만들고 Supabase 연동 값을 넣습니다. config.local.js는 Git에 추적되지 않도록 .gitignore에 등록합니다.

JavaScript
window.BUBIMAP_SUPABASE_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT_REF.supabase.co",
  supabaseAnonKey: "YOUR_SUPABASE_ANON_KEY",
};
VS Code 등의 에디터 터미널(또는 명령 프롬프트)에서 아래 명령어를 실행하여 로컬 웹 서버를 구동합니다.

Bash
python3 -m http.server 8080
(또는 Node.js 환경의 npx serve, VS Code의 Live Server 확장 프로그램 등을 사용해도 무방합니다.)

Vercel 배포
작업한 웹 소스코드 폴더 전체를 GitHub 저장소(Repository)에 커밋 및 푸시(Push)합니다.

Vercel 대시보드에서 해당 GitHub 저장소를 가져오기(Import) 합니다.

Vercel 프로젝트의 Settings > Environment Variables에 Supabase 환경변수를 등록합니다.

SUPABASE_URL = https://YOUR_PROJECT_REF.supabase.co

SUPABASE_ANON_KEY = YOUR_SUPABASE_ANON_KEY

배포(Deploy)가 완료되면 대시보드에 생성된 퍼블릭 URL을 통해 사이트에 접속합니다.

운영 흐름
데이터 자동화 수집: 백엔드 스크립트가 부산 공공데이터 API를 주기적으로 호출 및 정제하여 Supabase 테이블을 최신 상태로 유지합니다.

사용자 접근: 사용자가 웹 앱에 접속하면 브라우저의 GPS(Geolocation API)를 통해 위치 정보 제공 동의를 받습니다.

위치 기반 필터링: 사용자의 현재 좌표 기준 반경(1km/3km/5km) 내의 '수강료 무료' 조건 데이터를 Supabase에서 불러옵니다.

인터랙티브 지도 표시: 필터링된 결과값을 받아 지도 위에 마커로 시각화하며, 마커 클릭 시 카카오맵/네이버 지도 길찾기 페이지로 연동됩니다.

다음 확장 후보
사용자 북마크(찜) 기능: Supabase Authentication을 연동하여 자주 찾는 시설이나 관심 있는 무료 강좌를 저장하는 개인 보관함을 구현합니다.

PWA(Progressive Web App) 전환: manifest.json과 service-worker.js를 추가하여 모바일 기기 홈 화면에 앱처럼 설치 가능하도록 만듭니다.

강좌 마감 알림 서비스: Supabase Edge Functions를 활용해 마감이 임박한 인기 무료 강좌를 브라우저 푸시 알림으로 전송합니다.

커뮤니티 연동: 동일한 공공시설 강좌를 수강하는 지역 주민이나 대학생들끼리 소통할 수 있는 가벼운 실시간 오픈채팅 기능을 추가합니다.
